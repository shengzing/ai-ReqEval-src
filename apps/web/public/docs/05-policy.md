# 运行与留痕

控制配置发布与审计策略。

## 发布草稿

修改任意分区后，会自动生成草稿。点击「发布配置」正式生效。

- **发布需要变更原因** — 开启后必须填写变更说明才能发布，便于追溯
- **允许锁定阶段重跑** — 关闭后已锁定的阶段结果不能再生成

> 其他历史开关（提示词复核、记录模型输出、记录提示词快照）暂未启用，已从界面移除。

## 变更原因

发布时填写的变更说明会进入版本历史。填写要点：

- 用一句中文说清做了什么
- 例如「添加 vision 模型」「修正提示词缺少变量」
- 留空将拒绝发布（若开启了发布需要变更原因）

## 版本历史

「运行与留痕」分区底部显示所有发布过的版本：

- 发布时间
- 变更原因（无则记「无变更原因」）
- 当前生效版本带「当前」标记

点击每条右侧「加载」按钮，可把该版本配置载入草稿，编辑后重新发布即可回滚到该版本。
