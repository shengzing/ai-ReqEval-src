# 阶段 Skills

为每个阶段选择主 Skill、勾选启用的工具与子代理。这是项目设置最核心的分区。

## 主 Skill

每个阶段必须有一个主 Skill。选择后，该 Skill 允许的工具集与子代理集会自动填入「工具」「子代理」勾选区。

- 切换主 Skill 时，工具与子代理会重置为该 Skill 的默认允许集
- 当前的勾选状态不会保留，请切换前确认
- 若某个 Skill 在该阶段不可选，说明它的 `stage_suffix` 与当前阶段不匹配

## 触发方式

控制该阶段 Skill 何时执行：

- **手动** — 需要点击运行按钮才执行
- **输入就绪** — 依赖数据备齐后自动执行
- **自动** — 阶段进入时立即执行

> 默认是「手动」，便于调试。生产链路稳定后可切换为「自动」。

## 工具与子代理

勾选框同时承担展示与选择：

- 已勾选的工具/子代理以主色高亮
- 未勾选的灰色但仍可点
- 切换主 Skill 后，勾选状态会重置为该 Skill 的默认允许集

> 工具是 Skill 调用的能力单元，例如文档解析、风险识别。子代理负责执行 Skill 的细分任务，例如风险复核、价值复核。

## 版本

每个 Skill 有版本号，默认 `mvp-v1`。

- 该字段用于审计追溯：每次 Run 都会把当时的 Skill 版本号写入 StageResult
- 查看不同版本 Skill 跑出的结果差异时，可按该字段比对
- 当前只有 `mvp-v1` 一个版本，保持默认即可

## 常见问题

- **某 Skill 不在可选列表** — 它的 `stage_suffix` 与当前阶段不匹配，检查后端 Skill 定义
- **工具列表为空** — 该 Skill 没有定义 `allowed_tools`，或主 Skill 未选
- **版本字段为空** — 该 Skill 还没在配置中记录版本号，系统会用 `mvp-v1` 兜底
