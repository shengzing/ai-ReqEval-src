# 快速开始

欢迎使用项目设置。这里集中管理项目的模型、提示词、阶段 Skills 与运行策略。

## 入口

打开任意项目，进入「项目设置」即可看到五个分区：

- **模型** — 配置 LLM 端点
- **提示词** — 编辑每个阶段的提示词模板
- **阶段 Skills** — 为每个阶段选择主 Skill 与启用的工具/子代理
- **运行与留痕** — 控制发布、记录与审计策略
- **使用手册** — 即本页

## 推荐流程

1. 先在「模型」填入可用的 LLM 端点（Base URL 与 API Key）
2. 在「提示词」按需调整模板，保留必需的 `{{变量}}`
3. 在「阶段 Skills」为每个阶段选择主 Skill，勾选工具/子代理
4. 在「运行与留痕」开启必要的审计开关
5. 保存草稿，再发布

> 草稿不会立即生效，发布后才会写入新的配置版本。
