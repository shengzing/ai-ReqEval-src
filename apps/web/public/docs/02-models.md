# 模型配置

按兼容 OpenAI 的 Chat Completions 协议接入大语言模型。这里只保留模型名称、Base URL 与 API Key。

## 字段说明

| 字段 | 说明 |
|------|------|
| 角色标识 | 模型用途，如通用、视觉、推理 |
| 模型名称 | 传给 API 的 `model` 参数，例如 `gpt-4o-mini` |
| Base URL | 端点地址，例如 `https://api.openai.com/v1` |
| Key | API 密钥，以掩码存储，不会明文回显 |
| 启用 | 关闭后该角色不参与执行 |

## 填写要点

- Base URL 需包含到 `/v1` 这一级，否则部分服务会返回网关页
- 一个角色可对应多个能力，由后端按标签匹配
- 视觉模型需在能力标签中声明 `vision`，否则文档解析阶段不会调用
- 建议至少配置一个「通用」角色，阶段 Skills 才能正常 LLM 调用

## 安全

- API Key 在前端以密码框输入，发布后写入配置版本
- 审计日志会记录模型名称与配置哈希，但不记录 Key 本身
- 如需轮换 Key，直接编辑后保存发布即可
