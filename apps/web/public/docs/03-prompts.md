# 提示词模板

每个阶段、Skill 都可以挂一个提示词模板。模板支持 `{{变量}}` 替换，发布时会校验必需变量。

## 必需变量

下列变量在「阶段」类模板中必须出现，否则不允许发布：

- `project_goal` — 项目目标
- `stage_objective` — 阶段目标
- `evidence_summary` — 证据摘要
- `previous_stage_result` — 上阶段结果

## 编辑

1. 在「提示词」分区找到对应模板
2. 顶部标识模板的类别（stage / skill）、作用域、版本
3. 编辑正文，可用任何文本，注意保留 `{{变量}}`
4. 保存草稿后可点击「发布」生效

> 顶部红色提示会列出缺失的必需变量，补齐后才能发布。

## 变量替换规则

- 变量名前后必须是双花括号，例如 `{{project_goal}}`
- 变量区分大小写
- 未知变量保留原样，不会报错

## 版本与回溯

每次发布都会写入新的配置版本号，可在「运行与留痕」分区查看历史版本。回滚时一并回滚提示词。
