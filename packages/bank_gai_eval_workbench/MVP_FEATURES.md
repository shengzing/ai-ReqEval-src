# MVP 功能列表

## 1. MVP 目标

MVP 版本的目标不是做完整平台，而是先跑通一个“单场景前置评估闭环”：

1. 能创建一个评估项目
2. 能按四阶段录入和沉淀关键数据
3. 能形成目标SLA与Actual SLA对照
4. 能输出立项判断和证据底稿

## 2. MVP 范围

### P0 必做

#### 通用能力

- 项目创建与基础信息管理
- 四阶段状态管理
- 结构化表单录入
- 阶段产出物保存
- 证据附件索引
- 报告导出基础模板

#### 第一阶段工具

- 场景边界登记
- 业务流程/SOP摘要录入
- 参与方与责任链录入
- 风险分级矩阵编辑
- HITL配置表生成
- 审计留痕要求清单

#### 第二阶段工具

- 多主体价值网录入
- 实施税参数表
- 人工基线录入
- 目标SLA测算器
- 敏感性分析表

#### 第三阶段工具

- 原子任务清单编辑
- 评价量规配置
- 样本台账管理
- 微型探针测试记录录入
- Actual SLA自动汇总
- 错误分布与人工负担统计

#### 第四阶段工具

- 风险/目标SLA/Actual SLA 三维对齐面板
- 立项判据规则执行
- 决策卡生成
- 证据目录生成
- 评估报告底稿生成

### P1 可选增强

- Excel/CSV 批量导入
- 阶段模板复制
- 多场景横向比较
- 影子运行数据回填
- 量规版本管理
- 结论变更记录

### 暂缓项

- 多人协同审批流
- 复杂权限体系
- 与行内系统实时打通
- 全自动大模型编排
- 可视化大屏
- 复杂统计分析中心

## 3. MVP 页面/模块建议

- `项目总览`
- `阶段1 场景与风险`
- `阶段2 价值与门槛`
- `阶段3 任务与测试`
- `阶段4 判定与验证`
- `证据与报告`

## 4. MVP 验收标准

- 能完整录入一个主案例项目
- 能输出风险矩阵、实施税表、原子任务表、Actual SLA结果
- 能完成“立项/暂缓/不予立项”判断
- 能导出一份结构化评估底稿
- 所有阶段输入输出可追溯

## 5. 推荐实现顺序

1. 项目总览 + 阶段状态
2. 第一阶段工具
3. 第二阶段工具
4. 第三阶段工具
5. 第四阶段工具
6. 报告导出与证据归档
